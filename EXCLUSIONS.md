# Publication exclusions

This existing clean component repository is updated selectively. No private Git history, remote configuration, instructions, prompts, skills, personal workflow policies, agent registry, private configuration, destination IDs, account identifiers, calendars, documents, memories, journals, conversation/task history, logs, backups, environment files, OAuth/refresh tokens, credentials or private reports are included.

The private UI/Go server coupling, private scope/grant engine, daily review workflow, mail capture logic, specialist instructions and account-specific Notion/Gmail adapters are excluded. Those files couple generic mechanisms to private policy and runtime contracts; no attempt was made to sanitize them by broadly copying the application. Only generic reviewed mechanisms were adapted. The public outbound primitive cannot write, modify a mailbox or apply an approved record.

Only the explicitly pinned CC0 and project-generated artwork in ui/ASSETS.json is included. All other artwork and external binaries remain excluded, including unclear rights, trademark logos and private photographs. No private screenshots or fixtures are exported. Tests use invented values and no real message/page/database identifiers. Installed dependencies and emitted component output are local-only, ignored and absent from the publication manifest. Do not add those folders to a commit.

No original repository history, staged files, credentials or GitHub session is imported. Nothing is staged, committed or pushed by this update. No model or external account is activated. An absent file is not proof that a future change is safe: rerun the inventory/hash/privacy checks and inspect the full diff before committing. Do not use broad staging commands.
